Soonex is a Tableau + Corex launch template. The waitlist, journal, countdown chrome, cookie consent, and four skins ship wired. Your first hour should go to photography, copy, and the launch date—not rebuilding sections from scratch.

## Quick start

```bash
git clone https://github.com/corex-ui/soonex.git
cd soonex
mix deps.get
mix setup
mix server
```

Open `http://localhost:4999` after the alias finishes. The dev server checks that port 4999 is free before starting Tableau preview. Do not use `mix soonex.server`; the alias in `mix.exs` is `mix server`.

Production output lands in `_site/`. Run `mix assets.build` then `mix tableau.build` before deploy.

## Customize brand and SEO

Swap the lockup in `lib/layouts/brand.ex` and replace `extra/images/logo.svg`. Page titles and meta descriptions live in `lib/layouts/root_layout.ex` and per-page front matter. Set `SOONEX_PUBLIC_URL` in config when your origin is real so canonical URLs and Open Graph tags resolve correctly.

Use **bold**, *italic*, ***combined***, `inline code`, and ~~strikethrough~~ in journal posts—the Markdown pipeline supports GitHub-style extensions.

## Themes and skins

Overlay seeds, light/dark colors, radius, font, and typography in `config/config.exs`, then run:

```bash
mix corex.design.build
```

Visual composition lives in `assets/css/skins/{theme}.css`. Delete a skin file and its `@import` in `assets/css/site.css` to drop that look.

### Workflow

1. Edit `config :corex_design` for tokens
2. Run `mix corex.design.build`
3. Adjust skin CSS for layout differences
4. Switch themes from Template Options to verify contrast

## GitHub-style alerts

> [!NOTE]
> Contrast stays calculated. Do not lower `*-contrast` / `*-text` targets in the overlay.

> [!TIP]
> `mix server` fails clearly if port 4999 is already taken.

> [!IMPORTANT]
> Do not use token opacity such as `bg-surface/90`. Skins may `color-mix` a token against `transparent`.

> [!WARNING]
> Host overlays cannot set `*_scale`, duration, or opacity. The validator rejects those keys.

> [!CAUTION]
> Reduced motion disables scroll reveal, card lift, and skin JS.

## Footnotes

Launch date lives in `Soonex.Launch`[^alpha]. Header countdown appears after the hero[^beta].

[^alpha]: Change the target in one module. Hero badge and header timer both read it.
[^beta]: Header timer stays in flow (`invisible` + `inert`) until the hero sentinel is past.

## Code samples

Countdown helper:

```elixir
defmodule Soonex.Launch do
  @target ~U[2026-12-01 00:00:00Z]

  def countdown_ms do
    max(DateTime.diff(@target, DateTime.utc_now(), :millisecond), 0)
  end
end
```

Build pipeline:

```bash
mix deps.get
mix setup
mix assets.build
mix tableau.build
```

Skin loader entry:

```javascript
export function initSkins() {
  apply(document.documentElement.dataset.theme)
}
```

Inline: run `mix server` then open `http://localhost:4999`.
